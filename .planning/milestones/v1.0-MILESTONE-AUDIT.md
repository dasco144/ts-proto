## Tech Debt (Non-Critical)

All items are informational only — no blockers.

### Phase 02: Shared File Generator

- **INFO**: Comment in `src/generate-shared-helpers.ts` line 25 uses the word "placeholder" — false positive. The comment explains why `utils.globalThis` is excluded when `globalThisPolyfill=false`; it is not a code stub or incomplete implementation.

### Phase 03: Import Injection and Wiring

- **INFO (intentional)**: `tests/import-injection-test.ts` IMP-01 test (lines 41-50) verifies only the string construction of `conditionalUtils` path, not actual ConditionalOutput→import substitution behavior. This is an explicit design decision documented in the test itself — full E2E deferred to Phase 4. Phase 4 integration snapshots confirm the E2E behavior.

### Cross-Phase Architectural Note

- **INFO (architectural, expected)**: `integration/shared-helpers/proto-shared.ts` imports `Timestamp` from `./google/protobuf/timestamp` (a co-generated file). This creates a soft coupling: `proto-shared.ts` cannot be used in isolation without its sibling `google/protobuf/timestamp.ts`. This is expected behavior from how `makeTimestampMethods` in `src/main.ts` emits ts-poet `Import` nodes for `Timestamp` — it is a wellknown protobuf type, not a user-generated type, so GEN-05 does not apply. All 131 jest suites pass confirming no runtime issue.
